# Roadmap

## Phase 1 — MVP
- Slack webhooks
- GitHub webhooks
- Canonical event model
- Semantic retrieval
- Citation-based chat
- Multi-tenant auth scaffolding
- Dashboard + connectors UI

## Phase 2 — Organizational Intelligence
- Linear, Notion, Zoom connectors
- Kafka-compatible event bus abstraction
- Embedding workers and vector persistence
- Graph extraction and identity resolution
- Decision / goal / ticket linking
- Real-time notifications
- Tenant reindexing workflow

## Phase 3 — Autonomous Operations
- Goal alignment scoring
- Predictive risk models
- AI actions center with approvals
- Closed-loop execution feedback
- Policy engine and governance controls
